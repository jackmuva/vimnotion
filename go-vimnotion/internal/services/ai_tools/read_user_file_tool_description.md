Use this tool to read user-written content. Users may reference files (with the file's 
unique UUID) and ask for tasks like proofreading, grammar checks, or ideation.

## When to use this tool
Use this tool if a user references a file for the agent to read

<example>
User: {fileId: "123abc", fileName: "blogPost"} Write an engaging hook for this article
Agent: I'll use the read_user_content_tool to read the contents of "123abc" and work
    on writing a hook
</example>
